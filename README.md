#### 초기 성능 분석 및 개선 과제

1. 데스크톱 버전:
   - 사용하지 않는 자바스크립트 줄이기 (절감 가능: 77KiB)
   - 효율적인 캐시 정책을 사용하여 정적인 애셋 제공하기 (리소스 1개 발견됨)
   - 과도한 DOM 크기 지양하기 (요소 1,977개)
   - 자바스크립트 실행 시간 최적화 (0.9초)
   - 기본 스레드 작업 최소화하기 (1.3초)
   - 콘텐츠가 포함된 최대 페인트 요소 (410 밀리초)

2. 모바일 버전:
   - 기본 스레드 작업 최소화하기 (6.3초)
   - 콘텐츠가 포함된 최대 페인트 요소 (5,430 밀리초)
   - 자바스크립트 실행 시간 단축 (4.4초)
   - 사용하지 않는 자바스크립트 줄이기 (절감 가능: 77KiB)
   - 과도한 DOM 크기 지양하기 (요소 1,977개)
   - 긴 기본 스레드 작업 피하기 (긴 작업 15개 발견)

### 1.3 개선 목표

1. 데스크톱 버전:
   - Total Blocking Time (TBT) 760밀리초에서 200밀리초 이하로 감소
   - 사용하지 않는 자바스크립트 크기 77KiB 이상 감소
   - DOM 요소 수를 1,977개에서 1,500개 이하로 감소

2. 모바일 버전:
   - Largest Contentful Paint (LCP) 5.4초에서 2.5초 이하로 감소
   - Total Blocking Time (TBT) 4,570밀리초에서 1,000밀리초 이하로 감소
   - First Contentful Paint (FCP) 1.7초에서 1.2초 이하로 감소
   - Speed Index 4.9초에서 3.0초 이하로 감소

3. 공통 목표:
   - 효율적인 캐시 정책 구현
   - 자바스크립트 실행 시간 50% 이상 단축
   - 사용하지 않는 자바스크립트 코드 제거
   - DOM 크기 최적화
